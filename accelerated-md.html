True Escape Rate

Benchmark for calculating true rates of chemical reactions.

Adatom on Al(100) Surface

This benchmark tests various methods of calculating the true rate of escape. A tar file containing the minimized reactant state is found here: reactant.tar.gz.

This benchmark requires that rates are calculated at 150K with the langevin thermostat and the Verlet algorithm using a friction coefficient of 0.001 1/fs. Calculated rates will be compared with a standard true rate shown below.
